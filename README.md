# Java Student Management System

A Java-based application developed using Object-Oriented Programming principles to manage student records, course enrollment, and academic performance.

## Features

- Add student records
- Update student information
- Delete student records
- Search students
- Register courses
- Manage grades
- View academic performance
- Validate user input

## Technologies Used

- Java
- Object-Oriented Programming
- Collections Framework
- Exception Handling
- File Handling

## Skills Demonstrated

- Java development
- OOP design
- CRUD operations
- Data validation
- Problem solving
- Software development lifecycle
